# ShopBillingSystem-
Shop Billing System

Introduction

Shop Billing System is a simple Java project. It takes product names and prices from the user and calculates the total bill.

Objectives

- To understand Java programming.
- To use OOP concepts.
- To understand ArrayList.
- To calculate the total bill.

Technologies Used

- Java
- OOP
- Data Structures

OOP Concepts Used

1. Class
2. Object
3. Constructor
4. Encapsulation

Data Structure Used

ArrayList: It stores the product objects.

Features

- Enter two product names.
- Enter product prices.
- Display product names and prices.
- Calculate the total bill.

Sample Output

Enter product name: Pen

Enter price: 50

Enter product name: Book

Enter price: 200

Pen = 50

Book = 200

Total Bill = 250

Conclusion

This project helped me understand basic Java programming, OOP concepts and ArrayList.
